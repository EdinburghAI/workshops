# Intro to Machine Learning

This workshop introduces machine learning through linear regression on deliberately fake student data. Students explore a relationship between weekly alcohol consumption and attendance at the Big Cheese, fit a line, and extend the model to curved relationships.

## What Students Build

- Scatter plots using pandas and Matplotlib.
- A scikit-learn linear-regression model, with predictions and a fitted-line plot.
- An extension using a squared input feature to model a quadratic relationship.

All example data is synthetic; it should not be interpreted as evidence about real students.

## Run It

1. Import a student notebook into Kaggle, or open it in a local Jupyter environment.
2. For local use, provide pandas, NumPy, Matplotlib and scikit-learn.
3. Run the cells in order and complete the `TODO` prompts.

The current notebooks embed their data directly in Python. No CSV download or Kaggle dataset attachment is required.
